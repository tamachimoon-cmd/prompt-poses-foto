# Retrato de estúdio por ângulo (consistência de personagem / referência de pose)

## Uso

Gerar a mesma pessoa em vários ângulos (frente, perfil, 3/4) a partir de uma foto de referência, mantendo consistência.

## Prompt

```text
A studio portrait of [person] against [background], [looking forward/in profile looking right/etc.]
```

## Fonte

- Google AI for Developers — Gemini API: Nano Banana image generation (Prompting guide and strategies)
- https://ai.google.dev/gemini-api/docs/image-generation

## Dicas

Exemplo da fonte: "A studio portrait of this man against white, in profile looking right". A fonte orienta incluir as imagens geradas antes nos prompts seguintes e, para poses complexas, enviar uma imagem de referência da pose escolhida.
