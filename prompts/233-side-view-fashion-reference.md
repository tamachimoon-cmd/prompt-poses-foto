# 233 — Side view fashion reference

Finalidade: vista lateral para mostrar silhueta e perfil do figurino.

## Prompt (copiar)

Create a full-body side-view fashion reference of an adult model wearing an outfit. The model faces left in a comfortable upright stance, feet parallel and knees relaxed. The visible arm hangs slightly behind the side seam so the garment profile is easy to see. Keep the head facing the same direction as the torso. Frame the complete body and both shoes against a plain light gray background. Even studio lighting, no dramatic perspective, no added props, photorealistic.

## Por que funciona

Braço um pouco atrás revela o perfil da peça. Sem perspectiva dramática mantém proporções realistas para referência.
