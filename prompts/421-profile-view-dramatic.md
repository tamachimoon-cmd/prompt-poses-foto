# 421 — Profile View Dramatic

Finalidade: perfil artístico e escultural para retratos dramáticos ou conceituais.

## Prompt (copiar)

Photorealistic side profile photograph of an adult model standing, highlighting the outline of the face and silhouette, neutral or soft expression looking forward, plain neutral background or soft studio backdrop, dramatic side lighting creating clean edge, 85mm lens, eye-level, high detail on facial features and skin texture, photorealistic artistic portrait.

## Por que funciona

Perfil enfatiza forma e estrutura facial. Luz lateral define o contorno sem precisar de pose complexa de corpo.
