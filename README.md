# Prompt Poses Foto

Coleção curada de **10 prompts reutilizáveis para fotografia de estúdio com modelos adultos**, cobrindo retrato beauty, editorial de moda, corpo inteiro, perfil, pose sentada, movimento, headshot corporativo e iluminação criativa.

Os prompts foram construídos a partir de boas práticas de geração de imagem e fotografia: descrição clara do assunto, direção corporal objetiva, enquadramento, esquema de iluminação, lente, textura, fundo e restrições. A coleção é independente de plataforma e pode ser adaptada para ChatGPT Images, Adobe Firefly, Midjourney, Stable Diffusion, Flux e ferramentas semelhantes.

## Fórmula-base

Use esta ordem para criar variações sem transformar o prompt numa sopa de adjetivos:

```text
[finalidade e tipo de fotografia] + [modelo adulto e figurino] + [pose e direção do olhar] +
[enquadramento e ângulo] + [iluminação e fundo] + [lente e profundidade de campo] +
[texturas e acabamento] + [restrições]
```

### Exemplo curto

```text
Retrato editorial de estúdio de uma modelo adulta usando alfaiataria preta. Corpo a 45 graus, peso apoiado na perna traseira, cabeça voltada para a câmera e mãos relaxadas. Luz Rembrandt suave com softbox lateral, fundo cinza escuro, lente de 85 mm, pele natural e olhos perfeitamente nítidos. Sem texto, logotipos, anatomia distorcida ou retoque plástico.
```

## Como personalizar

Substitua os elementos entre colchetes quando aparecerem:

- `[modelo]`: descrição genérica ou uma pessoa de referência com autorização.
- `[figurino]`: alfaiataria, streetwear, vestido minimalista, moda conceitual etc.
- `[paleta]`: neutra, monocromática, complementar, tons terrosos etc.
- `[expressão]`: serena, confiante, contemplativa, intensa, espontânea.
- `[formato]`: 4:5 para editorial, 3:4 para retrato, 1:1 para avatar, 9:16 para redes sociais.

## Notas práticas

- Use uma imagem de referência de composição quando a ferramenta permitir e a pose precisar ser reproduzida com maior fidelidade.
- Configurações de câmera funcionam como vocabulário visual em geradores de imagem. Nem todo modelo simula fisicamente cada número.
- Para retratos, prefira olhos nítidos, fundos simples e lentes equivalentes a 50–105 mm para reduzir distorções faciais.
- Gere primeiro uma versão limpa; depois refine iluminação, roupa, expressão e cenário em etapas.
- Os prompts assumem modelos adultos. Respeite consentimento, direitos de imagem e regras da plataforma utilizada.
